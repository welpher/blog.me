LanTransport：把文件夹丢进局域网，对方打开浏览器就能拿

页面导航
✍️welpher.yu   2026-11-25    局域网开源Tauri

同一个 Wi-Fi 下传个文件，本来应该是最简单的事，实际却总要绕一大圈：微信先压一遍图，网盘要先传上去再下下来，U 盘拔来拔去。要是跨系统就更麻烦——Mac 上的资料给 Windows 同事、从 Linux 机器上拷点东西到笔记本、摄影现场把素材收到手机上，光是配 SMB、开共享、处理账号权限就够折腾一阵。

LanTransport 就是为了这一步做的：一个很小的桌面应用，选一个文件夹，点“开始共享”，同一个局域网里的任何设备——Mac、Windows、Linux、手机、平板——用浏览器打开链接，就能浏览和下载。发送端和接收端都不用配共享目录，也没有账号、云端和中继，文件不离开你的网络。

它长什么样 ​

打开的界面就这么点东西：选文件夹、设端口、开始共享，然后拿到一个 http://192.168.x.x:8000 的地址和二维码。把地址发给对方，或者让对方扫一下，事情就结束了。

整个流程可以压缩成三步：

  1. 选一个（或多个）要共享的文件夹
  2. 点 Start sharing
  3. 把链接或二维码给对方

默认是只读的。对方只能看和下载，不能改、不能删。

接收方什么都不用装 ​

这是它和“再做一个网盘”最大的区别：接收端零安装。手机、平板、另一台电脑，只要有浏览器就行。

截图是手机，但手机只是其中一种接收端。局域网里的另一台 Mac、Windows 笔记本、Linux 桌面，打开浏览器看到的是同一个页面。不用管对方是什么系统，也不用提前配 SMB、开共享文件夹或者处理账号权限——两台机器能互相访问到 IP 和端口就行。如果 Windows 第一次监听时弹出防火墙提示，放行即可。

发送端本身也是跨平台的：macOS（Intel 和 Apple Silicon）、Windows、Linux 用的是同一套代码。

页面里有目录列表、搜索、面包屑、文件大小和修改时间，图片和文本可以直接预览，其他文件点一下下载。下载走的是 HTTP Range，也就是支持断点续传，大文件传到一半断了可以接着来。

页面的语言会跟着访问者的浏览器走，目前有中文和英文，右上角也能手动切。

几个顺手的设计 ​

多个文件夹合并成一个列表。 不用把东西先归到一个目录里，添加几个文件夹，网页端看到的是合并后的内容；遇到同名文件会分行显示，并标出来自哪个文件夹。

上传是可选的，而且要 key。 打开上传开关后会生成一个 10 位 key，存在链接里或者手动填。文件落在第一个共享文件夹的 uploads/ 下，只增不改：不覆盖、不删除、不改名，重名自动加 (1)。key 可以随时轮换，适合“这次传完就作废”的场景。

可以设置浏览密码。 走 HTTP Basic，用户名固定是 share。在咖啡馆、酒店、会场这类不完全可信的网络里，至少别让人随手点开就能看。

关掉窗口不等于停止共享。 它是个托盘应用，关窗后还在后台跑，托盘里可以看状态、复制链接、开始或停止。

只监听局域网。 没有“仅本机”和“暴露公网”的开关，因为它本来就不是内网穿透工具。这个限制是故意的。

为什么安装包这么小 ​

桌面端用的是 Tauri 2，界面交给系统自带的 WebView，而不是像 Electron 那样捆一个 Chromium。HTTP 服务是 Rust 里的精简实现，只覆盖用得到的部分：GET / HEAD / PUT、Range、超时和连接数上限，HTTP/1.1 也只实现需要的子集。整个应用没有 Node 或 Python 运行时，安装包只有几 MB。

线程模型很朴素：accept 循环加每连接一个线程，上限 64，局域网场景够用，也就没有引入异步运行时。

安全边界得说清楚 ​

这类工具最怕被当成“公网文件服务器”用，所以边界写在明面上：

  • 没有 TLS。 浏览密码和上传 key 在局域网里是明文传输的，别在不可信网络里传敏感东西。
  • 默认没有认证。 不设密码时，能访问到这个端口的人都能看共享目录。
  • 只在可信局域网使用。 不要把端口映射到公网，它没有为此做任何防护。
  • 路径限制在共享根目录内。 每个请求都会 canonicalize 后检查是否越界，拒绝 ..、隐藏文件和指向根目录外的符号链接。
  • 上传只写不覆盖。 先写隐藏临时文件再 rename，重名加后缀，不提供删除和重命名。

浏览密码会以明文保存在本地配置文件里（Unix 下权限 0600），介意的话可以在输入框里点清除。更完整的威胁模型在仓库的 SECURITY.md 里。

安装 ​

macOS：

bash
brew install --cask welpher/tap/lantransport

Windows：

powershell
winget install welpher.LanTransport

Arch Linux：

bash
yay -S lantransport-bin

其他平台可以直接去 Releases 下载 .dmg、.exe / .msi、.AppImage / .deb / .rpm。

需要说明的是，目前的构建还没有代码签名。macOS 第一次打开会被 Gatekeeper 拦，需要右键 → 打开；Windows 会弹 SmartScreen。这不是病毒，只是还没买证书。

后面 ​

近期优先补的是代码签名和自动更新，然后是桌面端的上传进度和历史、按文件夹区分的上传链接，以及一个设备间传文本和图片的剪贴板通道。完整清单在仓库的 Roadmap 里。

项目是 MIT 协议，代码在 github.com/welpher/lantransport。翻译、平台适配、issue 都欢迎。

如果经常需要在同一个 Wi-Fi 下互相传文件，可以装一个试试。它不解决所有问题，但“选个文件夹，对方打开浏览器就能拿”这件事，它做得足够直接。
