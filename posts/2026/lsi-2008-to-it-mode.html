PIKE2008 HP9212-4i(4e) SAS2008 HBA卡 UEFI Shell 刷IT直通模式教程（纯UEFI、无DOS）

页面导航
✍️welpher.yu   2026-05-13    HBA卡

一、前言 ​

华硕PIKE2008、HP 9212-4i、LSI9211-8i 全部采用 SAS2008(B2) 主控。出厂默认IR硬件RAID模式，不适合NAS、Unraid、PVE、ZFS、黑群晖直通使用。

IT直通模式是存储用户最优选择：硬盘直连系统、无RAID锁、低占用、兼容性极强。

网上大部分老旧教程使用FreeDOS，需要开启CSM，新主板不兼容。本文采用Rufus官方一键下载UEFI Shell，无需手动下载Shell文件、无需手动改文件名，目前最简单、零出错刷卡方案。

二、适配卡片清单 ​

  • 华硕 PIKE 2008

  • HP LSI 9212-4i / 9212-4i4e

  • LSI 9211-8i

  • 所有 SAS2008 系列 HBA 阵列卡

三、所需文件 + 官方下载地址 ​

重点：UEFI 必须使用 .efi 文件，不要使用DOS版exe。

3.1 文件清单 ​

  1. sas2flash.efi（UEFI专用刷机工具）

  2. 214i4et.bin（SAS2008 IT固件）

  3. mptsas2.rom（卡引导ROM）

3.2 官方下载地址 ​

  • 9212 4i4e Broadcom官方固件包（含bin+rom） 直链：https://docs\.broadcom\.com/docs/9212\_4i4e\_Package\_P20\_IR\_IT\_FW\_BIOS\_for\_MSDOS\_Windows\.zip 解压提取： IT固件：Firmware\\HBA\_9212\_4i4e\_IT\\214i4et\.bin ROM文件：sasbios\_rel\\mptsas2\.rom 其它版本一定要去找自己卡的版本，不然会有问题

四、Rufus 一键制作 UEFI Shell 启动盘（当前最简正确方法） ​

纠正网上错误：新版Rufus 可以直接下载 UEFI Shell，不需要手动下载efi、不需要手动新建EFI文件夹。

4.1 Rufus 参数设置（照抄即可） ​

  • 设备：选择你的U盘（≥1GB）

  • 引导选择：下载 UEFI Shell（重点！不要选FreeDOS、不要选非可引导，一般来说下载2.0版本就行）

  • 版本：选择 x64

  • 分区方案：GPT

  • 目标系统：UEFI（非CSM）

  • 文件系统：FAT32

4.2 制作流程 ​

  1. 点击右下角开始。

  2. 弹窗确认，Rufus自动下载官方纯净UEFI Shell并写入U盘。

  3. 等待制作完成，无需任何手动改文件、改目录。

4.3 放入刷机文件 ​

制作完成后，把以下三个文件直接复制到U盘根目录：

  • sas2flash.efi

  • 214i4et.bin

  • mptsas2.rom

五、主板BIOS设置 ​

  1. 开机按 Del / F2 进入BIOS

  2. 关闭 CSM 兼容模块

  3. 关闭 Secure Boot 安全启动

  4. 启动模式改为：UEFI Only

  5. 第一启动项选择：UEFI U盘

  6. 保存重启

六、UEFI Shell 刷卡流程（顺序绝对不能乱） ​

6.1 进入U盘 ​

开机自动进入Shell，输入命令：

Plain
fs0:
dir

找不到就试 fs1:、fs2:，能看到刷机文件即为正确盘符。

6.2 刷写命令（逐条执行，等跑完再下一条） ​

① 彻底擦除原厂IR固件 ​

Plain
sas2flash.efi -o -e 7

⚠️ 执行后卡片变成裸卡、无固件、提示不可用，属于正常现象。

② 写入IT固件+ROM ​

Plain
sas2flash.efi -o -f 214i4et.bin -b mptsas2.rom

出现 Finished Processing Commands Successfully 代表刷写成功。

③ 重启（必须重启！） ​

Plain
reset

重启再次进入UEFI Shell，此时卡片固件恢复正常。

④ 写入原厂SAS地址（防掉盘） ​

查看卡背面贴纸，以 500605B0 开头，去掉横杠空格。

Plain
sas2flash.efi -o -sasadd 500605B0XXXXXXXX

七、验证是否刷写成功 ​

  1. 拔掉U盘，正常开机。

  2. 开机自检观察LSI SAS2008信息。

  3. PRODUCT IDENTIFIER 显示 SAS2008-IT 即为成功。

八、常见报错说明 ​

报错：Controller is not operational ​

原因：执行完 \-e 7 擦除，卡片无固件。

解决：先刷固件 → 重启 → 再写SAS地址，顺序不可逆。

报错：File not found ​

文件不在根目录、文件名写错、U盘非FAT32格式。

九、硬性注意事项 ​

  • 刷写全程禁止断电、强制重启，会直接变砖。

  • 不要乱填SAS地址，必须使用卡片原厂地址。

  • 本教程为纯正UEFI，适配所有新主板，不兼容老旧CSM方案。
